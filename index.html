Make your own 2D game.

2plat is a free game maker for Windows. Draw sprites, build levels, set up how things behave with clicks, then play your game or export it as a web page anyone can open.

Download for Windows

Everything for a game is in one editor

  • Sprites

    A pixel editor with animation frames, onion skinning, mirror drawing, and PNG import and export.

  • Objects and rules

    Pick how something behaves, like a platformer hero, a patrolling enemy or a turret. Then add rules such as “when the player touches a coin, add 10 to score.”

  • Levels

    Paint levels with brush, rectangle and line tools. Zoom, undo, and copy and paste whole areas.

  • Sound and music

    Design sound effects from waveforms and write music on a piano roll.

  • Playtest and export

    Press F5 to play right away. Export one HTML file that runs in any browser, with touch controls on phones.

  • Templates

    Start from Blank and build everything yourself, or open Sky Hopper (platformer) or Gem Dungeon (top-down) and change anything.

Prefer the terminal?

The command-line tool works without opening the editor. Push PNG images or pixel code into sprites, and play a game straight from the command line.

:: make a project, add sprites, play it
2plat-cli.cmd new mygame
2plat-cli.cmd push-png mygame hero.png --frames 4
2plat-cli.cmd push-code mygame coin.txt
2plat-cli.cmd play mygame

Images must be PNG files. Run 2plat-cli.cmd help to see every command.
